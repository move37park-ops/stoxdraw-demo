# STOXDRAW — 차트에 직접 그리는 미래 가격, 실력으로 증명하는 예측 네트워크

> **"유저에게는 승부욕을, 시장에는 검증된 집단지성 데이터를 제공합니다."**  
> STOXDRAW는 단일 핵심 차트(**`BTC/USDT · 향후 20일`**) 위에서 변곡점 클릭만으로 미래 가격 경로를 직관적으로 작도하고, 시스템이 이를 20개 일봉 시계열 데이터로 즉시 보간·박제한 뒤 실제 시장 종가와 대조하여 **브론즈~다이아몬드** 티어로 실력을 증명하는 예측 인텔리전스 플랫폼입니다.

---

## 전체 서비스 구조 (Lean 3-Tab Architecture)

Vercel Geist 디자인 시스템(`vercel-geist.css`, `design.md` & `design.dark.md`)을 기반으로, 유저 몰입과 구조화된 데이터 수집에 집중한 3탭 구조로 설계되었습니다.

```
┌──────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│  ▲ STOXDRAW [BTC/USDT · 20일] | Live 실전 예측   Practice 리플레이 랩   리더보드 & 내 기록    [D-0][D+5][D+12][D+20] │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────┘
         │
         ├─── 1. Live 실전 예측 스튜디오 (/)
         │       • 폴리라인 캔버스: 과거 30일 실제 일봉 + 향후 20일 변곡점 클릭/드래그 작도
         │       • 20일 가격 자동 보간기: 클릭한 변곡점 사이를 20개 일봉 시계열 가격으로 즉시 선형 보간
         │       • Contribution-to-Unlock: 내 예측을 먼저 제출해야 Crowd Median & Top Forecasters 잠금 해제
         │       • 버전 박제 원장: 사후 삭제 불가, 최초 제출본(v1)과 수정 이력(v2+) 투명 보존
         │
         ├─── 2. Practice 리플레이 랩 (/practice)
         │       • 과거 BTC/USDT 주요 변곡점 구간 블라인드 퀴즈 (4개 기출 스테이지)
         │       • 제출 즉시 1초 결과 공개: 20일을 기다리지 않고 실제 20일 정답 궤적 및 100점 채점표 즉시 확인
         │       • 부담 없는 훈련: 공식 평판(LP) 차감 없이 별도 연습 점수로 실력 연마
         │
         └─── 3. 리더보드 & 내 기록 (/leaderboard, /record, /f/:id)
                 • 브론즈(Bronze) ~ 다이아몬드(Diamond) 5단계 실력 기반 티어 시스템
                 • 일별(D+1 ~ D+20) 예측가 vs 실제 종가 대조 정산 매트릭스
                 • 티어 및 20일 예측 경로가 담긴 고해상도 바이럴 공유 카드 이미지(PNG) 발급
```

## 핵심 도메인 엔진 (4 Core Engines)

1. **가격 보간기 (`src/domain/interpolation.ts`)**: 유저가 찍은 변곡점(`AnchorPoint[]`)을 즉시 20개 일봉 시계열(`number[20]`)로 선형 보간하여 모든 참여자의 전망을 동일한 규격으로 저장합니다.
2. **버전 관리 원장 (`src/data/localRepository.ts`)**: 최초 제출본(`v1`)을 영구 박제하고, 전망 수정 시 `v2, v3` 리비전을 추가(Append-only)하여 사후 은폐를 방지합니다.
3. **20일 정확도 채점기 (`src/domain/scoring.ts`)**: 경로 오차(50점), 방향성 일치도(30점), 변동성 대비 목표가 정밀도(20점)를 종합하여 100점 만점으로 자동 채점합니다.
4. **티어 & 컨센서스 집계 (`src/domain/elo.ts`, `src/domain/crowd.ts`)**: 브론즈~다이아몬드 승급 산정 및 20일 Crowd Median·분포도(P15~P85)·상위 고수(Top Forecasters) 시나리오를 집계합니다.

## 실행 및 검증 방법

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 도메인 단위 테스트 실행 (Vitest 24개 테스트)
npx vitest run

# 프로덕션 빌드 및 타입 검증
npm run build
```
